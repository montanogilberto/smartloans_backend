Manage one company's employee records with the provided JSON.

Every action is scoped by companyId: updating or deleting another company's
employeeId returns "Employee not found". Delete is refused while payroll
expenses or project assignments reference the employee — set statusId=2
(Inactive) + endDate instead.

Parameters:
    ```
    Actions:
    INSERT --> 1
    UPDATE --> 2
    DELETE --> 3 (only companyId + employeeId + action needed)
    JSON
    {
      "employees": [
        {
          "companyId": 1008,
          "employeeId": 0,
          "firstName": "Ana",
          "lastName": "López",
          "email": "ana@example.com",
          "phoneNumber": "6621234567",
          "address": "",
          "employmentTypeId": 1,
          "position": "Cajera",
          "departmentId": 3,
          "statusId": 1,
          "hireDate": "2026-09-01",
          "endDate": "",
          "emergencyContactName": "",
          "emergencyContactRelationship": "",
          "emergencyContactPhone": "",
          "notes": "",
          "action": 1
        }
      ]
    }
    ```

Returns:
-     { "status": "success" | "error", "message": "...", "value": "<employeeId>" }
