Registers a mobile device token in Azure Notification Hub so push notifications can be targeted by user tag.

Required header:
  x-worker-key: <WORKER_KEY>

Request body (JSON):
{
  "userId": 123,
  "token": "fcm_or_apns_device_token",
  "platform": "android", // or "ios"
  "appEnv": "prod",       // optional → tag env_{appEnv}
  "appId": "gmoprestamos" // optional → tag app_{appId} (which GMO app installed it)
}

Behavior:
- Validates required fields: userId, token, platform.
- Maps platform to Azure NH installation platform:
  - android -> fcmv1
  - ios -> apns
- Creates/updates an Azure Notification Hub Installation with:
  - pushChannel = token
  - tags includes user_{userId} (+ env_{appEnv}, app_{appId} when sent)
- With env PUSH_TARGET_APP=gmoprestamos, sends target "user_{id} && app_gmoprestamos",
  so pushes reach only that app (not POS Vending installs of the same user).
- Returns success/error details including upstream status code when available.
